Referencias del plano

    Cómo verlo dentro de Home Assistant
    1. Copiá este archivo a la carpeta /config/www/ de Home Assistant con el nombre colegio3d.html (por ejemplo con el complemento File editor o Samba). Si la carpeta www no existe, creala y reiniciá Home Assistant.
    2. En el panel, agregá una tarjeta Página web (Webpage) con la URL /local/colegio3d.html. También podés usar un panel lateral con la integración Webpage.
    3. Al abrirse dentro de Home Assistant, la etiqueta de arriba cambia a “En vivo”: luces, ventiladores, aires, proyector, pantalla, humo y cortes se dibujan según el estado real de las entidades, y los botones de modo cambian los input_select de cada área.
    4. Si alguna entidad tiene otro nombre en tu instalación, corregila en el bloque ENT al inicio del script. Las que no se encuentran se listan debajo de los botones.

    La conexión usa la sesión ya abierta de Home Assistant (la página se sirve desde el mismo servidor), así que no hace falta un token.
